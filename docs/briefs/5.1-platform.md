# Brief 5.1: the SDL host's window, input, clock, files and settings (P2, P3, P4)

Milestone 5.1 of `docs/milestones.md`. Specification: `docs/specs/platform.md` sections 1 to 4, 7,
8 and 11, `rtl-shim.md` section 7 (`IRtlHost`). The headless host (`src/Headless`, brief 2.3)
implements the same interface without a display. Read `parallel-tracks.md` in this folder first.

You write in your product worktree under `src/Platform` and `src/Game`. The design session
created `src/Platform/Aow.Platform.csproj` with the package `ppy.SDL3-CS` and restored it, which
gives the SDL3 binding and its native libraries for Windows and Linux: add no other package.
Keep the binding use thin, behind the host interfaces, as section 1 says.

## What to build

1. The window and presenter of section 3: one window, one thread, the software framebuffer
   presented as a texture, scaling, the event pump, and the input mapping of section 3 (virtual
   keys, mouse buttons, double-click synthesis). A presenter that shows a test pattern is enough
   until the graphics track lands.
2. The clock and pacing of section 4.
3. The file service of section 7 (the two layers, case-insensitive lookup, current directory
   emulation) and the settings of section 8 (the shim's `Registry` (Delphi `TRegistry`) over a settings file), shared
   with the headless host where they are the same.
4. `src/Game`, the executable, starting the SDL host with the GOG directory as the data root and
   showing a window with the test pattern. The full startup through `MainForm` (Delphi `TMainForm`) is milestone 5.3.
