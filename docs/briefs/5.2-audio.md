## What to build

1. **A thin libopenmpt binding** of our own in `src/Platform` (P/Invoke over the C API of
   `libopenmpt.h`: create a module from memory, set the repeat count, render interleaved stereo,
   read and set the order position, destroy), loading the library by the name vcpkg gives it
   (`openmpt.dll` on Windows, `libopenmpt.so` on Linux) through a `NativeLibrary` resolver,
   with a clear message and silence, not a crash, when the library is missing.
2. **The audio backend of section 5**: an SDL audio stream and a mixer, the WAV reader for the
   game's sound effects, songs through libopenmpt, and the Galaxy backend's volume, panning, fade
   and loop semantics as a new `TSoundSystem` descendant, replacing the 26 sound TODOs. The fade
   state machine is transcribed from `GalSndS.pas`.
3. **Startup with music**: `src/Game` plays `TITLE.IT` on the title scene as the original does.
4. **Silence on this PC**: every automated check runs with a null audio device or a muted stream,
   and the game executable takes a `--mute` option that the checks use. Nothing plays audibly
   during a check. The user listens to the result interactively.
