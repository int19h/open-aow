## Scope

Every class with a split initializer or a guarded static factory in `src/Units/*.cs` except these,
which other briefs own: `AoWE.cs` and `AoWE.*.cs`, `Engine*.cs`, `HSEngine*.cs`, `NetworkE.cs`,
`Sound*.cs`, `ImageLib*.cs`, `GFXE*.cs`, `DisplayC*.cs`, `IsoHex*.cs`, the spell and ability files
(`PassiveAb.cs`, `*Spells.cs`), and every user-interface component, meaning any class that descends
from `TComponent` or `TControl` (windows, panels, grids, menus, list and edit controls, tool tips).
The interface components are a later layout brief. Your scope is the map objects and structures
(nodes, altars, mines, farms, towers, signs, storms and the like), the AI units (`BehaviorAG`,
`IndependentAG`, `MainAG`, `AGCPlugins`), `EventLog`, `AoWTC`, `AoWSetup`, `City` and the other
game-object units. Do not edit `AoWE.cs`: another run converts the unit hierarchy there at the same
time. A class whose base in `AoWE.cs` still has no semantic constructor is listed as not converted
for a final sweep.

List every class in scope first in the status file with its bodies and the shape the rule gives
it.

- **Plain:** the body only assigns fields, allocates private children, or calls virtual methods
  whose overrides do the same.
- **Context-guarded:** the body publishes the object (owner insertion is already done by
  `TEObject`, so this means a further list, cache, global or registry) or acquires something its
  `Destroy` releases, and later work on the chain can throw.
- **Not converted:** anything that fits neither cleanly (work before the base body that the base
  observes, a skipped base initializer, reentry on an existing object, a raw `NewInstance`
  consumer). Leave such a class as it is, list it in the report with the line and the reason, and
  continue with the rest. Do not stop the run for it.

`TEventLog` is one of the design note's ordering exceptions: it snapshots game state before owner
callbacks publish it. Leave it on its legacy route unless a field initializer or constructor order
reproduces that exactly, pinned by a test on the base commit.

Keep ordinary virtual calls at their current positions and `base.X()` calls that stand for Delphi
`inherited` as non-virtual calls. Do not move work into field initializers. A parameterless
constructor stays only for a named raw consumer. Callers inside your worktree use `new` or the
guarded factory. Callers in the private repository are listed in the report with a ready patch.
A static factory with a `new` modifier that no longer hides anything loses the modifier. Do not
add warning pragmas.
