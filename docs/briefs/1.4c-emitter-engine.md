# Brief 1.4c: the emitter, overrides and report, for Engine

The emitter part of milestone 1.4 of `docs/milestones.md`, measured on the Engine set. The
probe path (transpiling the probes and comparing their output, T4) is brief 1.4d. Specification:
`docs/specs/transpiler.md` sections 1 (outputs), 2 (stages 5 to 8), 3, 4, 5, 6 (applying the
resolutions of brief 1.3), 7, 8 and 9, and done measure T3 of section 11. `docs/specs/rtl-shim.md`
is the shim the output compiles against, and `src/Rtl` in `D:\git\open-aow` is its implementation
(briefs 1.4a and 1.4b). Read the transpiler sections in full first: they are the mapping, and this
brief does not repeat them.

You work in `D:\git\open-aow-private` on the transpiler under `tools/transpile/`, and you write
the generated output and the Engine overrides into `D:\git\open-aow`. Read both `AGENTS.md`
files. The sandbox has no network. The design session added
`Microsoft.CodeAnalysis.CSharp` to `Transpiler.csproj` and restored it: add no other package.

## What to build

1. **Emitter.** Stage 6 of section 2: from the typed and normalized tree, build Roslyn syntax
   trees with `SyntaxFactory`, never C# text, for every construct of sections 3, 4 and 5 that the
   Engine set uses, with the comments section 3 requires as trivia. Write each file through
   `NormalizeWhitespace`, parse it back with Roslyn, and treat a syntax diagnostic as an internal
   error (section 1). Apply the brief 1.3 resolutions (rules N1 to N12) where they occur. An
   unmapped construct becomes the `TODO` throw of section 9 item 2 and an error line in the
   report, so the project still builds.
2. **The Engine set.** `Engine`, `EList`, `FMemStr`, `PlugInM` and `inc/HashTab` (an include of
   Engine) from `units.toml`, emitted into `D:\git\open-aow\src\Generated\<Unit>.cs` in the
   project `src/Generated/Aow.Generated.csproj`, which references `src/Rtl` and turns `Nullable`
   off, added to the root solution. The generated project builds with the root
   `Directory.Build.props`, so warnings are errors there too: emit code that compiles clean, and
   where a warning is inherent to the calque (unused locals from `= default`, unreachable code
   after `Exit`), disable that warning number in `Aow.Generated.csproj` with a comment saying why,
   and list the numbers in the report.
3. **Overrides.** The manifest `src/Overrides/overrides.toml` and the project
   `src/Overrides/Aow.Overrides.csproj` (or the files compiled into the generated project, as
   section 8.1 implies: choose one, say which and why), read by stage 7. The Engine overrides:
   the 4 `Fill*` routines and `BitList.Get` (Delphi `TBitList`) and `Put` from the Pascal equivalents in
   `D:\git\open-aow-private\data\asm-routines.json`, keeping the edge cases section 8.2 lists, and
   the stub overrides of the clipboard and popup menu members of `EngineComponent` (Delphi `TEComponent`)
   (`docs/design.md` section 3). The 9 `ReturnAddr` list-error helpers map to the shim's raise.
   Rules A1 to A3 of section 8.2 where Engine has them.
4. **Startup.** `Aow.Units.Startup` with `InitializeAll` and `FinalizeAll` of section 4.8,
   restricted to the units emitted so far, with the order from brief 1.3.
5. **Report and demand list.** `src/Generated/report.md` with the sections of section 9 that the
   Engine run produces, and `src/Generated/shim-demand.md`.
6. **The command.** `dotnet run --project tools/transpile/Transpiler -- emit --source
   D:\git\aow\src\delphi3 --rtl C:\Tools\Delphi3\SOURCE --data D:\git\aow\data --port-data
   D:\git\open-aow-private\data --overrides D:\git\open-aow\src\Overrides\overrides.toml --out
   D:\git\open-aow\src\Generated [--set engine]` emits the named set. Two runs give byte-identical
   output.

Where the generated code needs a shim member that `src/Rtl` lacks, add it to `src/Rtl` with a
test, following `rtl-shim.md` and the Delphi source, and list it in the report. Where the
specification's mapping does not compile or is ambiguous for a construct Engine uses, choose the
smallest fix, keep it consistent with the three consequences at the head of `transpiler.md`, and
list it in the report as a proposed specification change: the design session folds it in.

## Tests

Golden tests in `tools/transpile/Transpiler.Tests/` for the emitter: one Delphi snippet per
construct group of sections 4 and 5 that Engine uses, with the expected C# compared after
`NormalizeWhitespace` on both sides. A test that compiles the emitted Engine project in memory
with Roslyn against `Aow.Rtl.dll` is welcome but not required.

## Out of scope

The units beyond the Engine set, the probe path (brief 1.4d), the graphics and image library
overrides.

2. T3 of `transpiler.md` section 11: the emit command for the Engine set writes the files, and

3. The report's TODO count, the list of disabled warning numbers, the shim members added, and the

4. A second emit run leaves `src/Generated` unchanged (`git -C D:\git\open-aow status` shows no
