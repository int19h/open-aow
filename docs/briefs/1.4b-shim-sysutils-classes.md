# Brief 1.4b: the RTL shim's SysUtils and Classes

The second shim part of milestone 1.4 of `docs/milestones.md`. Specification:
`docs/specs/rtl-shim.md` sections 3 (SysUtils), 4 (Classes), 6 and 8, with `transpiler.md`
sections 4 and 5 for how generated code calls them. Brief 1.4a built the core types and the
System unit in `src/Rtl` (read its code and tests first: this brief extends them in the same
style).

You work in `D:\git\open-aow`, the product repository. Its `AGENTS.md` holds the standing rules.
Read `C:\Tools\Delphi3\SOURCE\RTL\SYS\SYSUTILS.PAS` and `C:\Tools\Delphi3\SOURCE\VCL\CLASSES.PAS`,
the reference for every behavior, and the probe recordings under
`D:\git\open-aow-private\tests\probes\` (`expected\*.txt` and the probe sources) freely. Write
only under `src/`. The sandbox has no network and the packages of `src/` are restored: add no new
package.

## What to build

- SysUtils, `rtl-shim.md` section 3: the string routines of 3.1, the locale comparison of 3.2,
  `Format` of 3.3, files and paths of 3.4 (through a small file system interface in the shim with
  a default implementation over `System.IO`, since the host interface of section 7 is a later
  brief: name it so that the host brief can replace the default), the enumeration order of 3.5,
  time of 3.6 with the clock behind the same kind of replaceable interface.
- Classes, section 4: `TList` with `CLASSES.PAS`'s `Grow` and `QuickSort` ported as written,
  `StringCollection` (Delphi `TStrings`), `StringList` (Delphi `TStringList`), `TStream`, `TMemoryStream`, `TFileStream`, `Persistent` (Delphi `TPersistent`),
  `TComponent` with the `CLASSES.PAS` destruction order, and `Rtti.PublishedProperties`.
- Port algorithms from the Delphi source method by method where section 4 says so, with a comment
  naming the Delphi routine each one follows.

Where the spec and the Delphi source or a probe recording disagree, the recording wins over the
source and the source wins over the spec: implement that, test it, and list the disagreement.
Brief 1.1's probe README already found two: `StrToInt` rejects decimal `-2147483648` and accepts
`$FFFFFFFF` as -1, and a string argument in `Format`'s star-width slot does not raise.

## Tests

In `src/Rtl.Tests/`, in the style of brief 1.4a, with the probe recordings as fixtures read from
the private repository at test time (skipped with a clear message when the path is absent):

- `strings.txt`: every line brief 1.4a skipped as SysUtils, including the 65,536-line
  `AnsiCompareText` block (equality and sign must match on every pair: section 3.2 says the order
  differs from Windows for punctuation and accents, so if signs differ, report how many pairs and
  of which kind, and compare equality only for those, with the list in the report).
- `format.txt`, `lists.txt`, `streams.txt`, `files.txt` in full. `files` needs the same prepared
  directory the probe builds: recreate it in a temporary directory in the test.
- Unit tests for every public member the fixtures do not cover.

## Out of scope

The VCL parts of section 5, the host interface of section 7 (only the replaceable defaults named
above), the transpiler, anything outside `src/`.
