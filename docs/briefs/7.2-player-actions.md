# Brief 7.2: the main player actions, each pixel-identical to the original

The second step of milestone 7 of `docs/milestones.md`. Brief 7.1 drove a scripted player from the
title scene to the end of the first turn, with every screen and the game state equal to the
original's. This brief applies the same method, fixtures captured from the original and matched
by the port, to the main things a player does in a game.

You work in `D:\git\open-aow` on the branch the prompt names, and in `D:\git\open-aow-private`
under `tools` and `tests/frames`. Read both `AGENTS.md` files, `tests/frames/report.md` and the
7.1 report (`D:\git\open-aow-private\data\graphics\7.1-report.md`).

## The scripted paths

Each path starts from a save (a human seat in Mountain Clash or another shipped scenario, made by
the 7.1 path or by the original), and each screen it passes is a fixture captured twice from the
original, with the game state saved at the end of the path:

1. **Save and load through the file dialog**: open the save dialog, type a name, save, return to
   the title scene, load that save through the load dialog, and reach the same map frame.
2. **Tactical combat as a human**: attack an enemy army, fight the battle in the tactical view
   (move a unit, attack, end the combat round), and return to the map. Also the same attack with
   auto-combat.
3. **A spell**: open the spellbook, cast an adventure spell on the map, and the frame after it.
4. **A city**: open a city, change its production, close it, end the turn, and the city's state on
   the next turn.
5. **Diplomacy and events**: open the relations window, the events window and the realm window.
6. **Several turns**: five human turns in a row with a fixed sequence of orders, so that the
   computer players' turns run between them, with the state compared after each turn.

## Rules for native runs on this PC

Native runs go through the copied harness on its hidden desktop, with sound and music volume 0,
the game's registry key verified restored after every run, processes stopped only by the PID the
harness recorded, and an immediate stop if a window or dialog appears on the user's desktop.

## Done measure

Every new fixture equals its reference with no masks, every saved state equals the original's,
`python tools/check.py` passes with the new fixtures, and the TODO count is reported before and
after. A path that cannot be made equal is reported with the first differing frame or state and
its cause. Report the paths, the fixes with what pins each one, and anything not done. Keep a status
file at `D:\git\open-aow-private\tools\obj\7.2-status.md`.
