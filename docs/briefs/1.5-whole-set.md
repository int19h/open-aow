## What to build

1. **Emission of the whole set.** `emit --set all` (keep `--set engine`) emits every `transpile`
   unit into `src/Generated`. Decide the project split by build time and dependency order (one
   project, or one per Delphi package with the package `requires` as project references), say
   which and why in the report. Every construct of the set that brief 1.4c did not need gets its
   mapping from the specification, with a golden test.
2. **Assembler rules.** A1 (constants) and A2 (thunks, with the catalogue's argument mapping) and
   A3 (the `MapField` (Delphi `TMapField`) allocator) generated, every one listed in the report.
3. **Overrides.** From `D:\git\open-aow-private\data\asm-routines.json`'s Pascal equivalents: the
   `bitop`, `fill` and `hex-coords` routines with the edge cases section 8.2 lists (the
   `asm-stubs` probe then covers them, so its pending lines become matches), and the 52 `other`
   routines, keeping the original behaviors section 8.2 names. The 32 `blitter` routines get stub
   overrides that throw `NotImplementedException` with the routine name, listed in the report as
   owed to milestone 3. The overrides `transpiler.md` names elsewhere (the two Boolean byte sites
   of section 7 trap 9, the N6 reinterpretations, the six diagnostics brief 1.3 left for
   overrides, `EngineComponent` (Delphi `TEComponent`) stubs that already exist) are written as specified.
4. **Startup.** The full `InitializeAll` and `FinalizeAll` from the `AoW.exe` table.
5. **Report.** All sections of section 9 for the whole set.

Every mapping question the specification does not answer, and every place where the specified
mapping does not compile for a construct of the set, is listed as a proposed specification change
with the smallest fix you chose. Generated output is never edited by hand.
