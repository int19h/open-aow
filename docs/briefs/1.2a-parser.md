# Brief 1.2a: the transpiler project, the unit list, the preprocessor, the lexer and the parser

First half of milestone 1.2 of `docs/milestones.md` (the resolver is brief 1.2b). Specification:
`docs/specs/transpiler.md` sections 1, 2 (stages 1 to 3), 10 and 11, and `docs/design.md`
section 3 (the transpile set table). Read those first, in `D:\git\open-aow\docs\`.

You work in `D:\git\open-aow-private`. Its `AGENTS.md` holds the standing rules. Read the
recovered source under `D:\git\aow\src\delphi3` and the Delphi 3 RTL and VCL sources under
`C:\Tools\Delphi3\SOURCE` freely. Write nothing outside `D:\git\open-aow-private`.

## What to build

### 1. The project

- `tools/transpile/Transpiler.slnx` (or `.sln`) with `tools/transpile/Transpiler/Transpiler.csproj`
  (console, `net11.0`) and `tools/transpile/Transpiler.Tests/Transpiler.Tests.csproj` (xUnit).
- A `Directory.Build.props` under `tools/transpile/` with the same defaults as the product's
  (`D:\git\open-aow\Directory.Build.props`: `net11.0`, nullable, warnings as errors,
  deterministic) and a `global.json` there pinned like the product's (`D:\git\open-aow\global.json`).
- Package references: `Microsoft.CodeAnalysis.CSharp` is not needed yet (the emitter is a later
  brief), so add no packages beyond xUnit and its runner. Use the newest stable xUnit that runs on
  `net11.0`.
- C# 15 is the language version. Use records for the syntax tree, pattern matching, collection
  expressions. This is tooling, so clear code beats clever code.

### 2. The unit list

`tools/transpile/units.toml`: one entry per unit of the transpile set, with its path relative to
`D:\git\aow\src\delphi3`, its package, and its treatment (`transpile`, `skip`, `rewrite`, `drop`,
`later`), taken from the table in `docs/design.md` section 3 and resolved to files through the
package files (`*.dpk`) and the program files under `src/delphi3`. Every unit of every package
the table names appears, so that the treatment of each one is explicit. Units the table excludes
by name (for example `AoWDialogForm`) get their treatment and a short reason. Include files are
not listed; they are found through `{$I}`.

A small TOML reader is enough (the file uses only tables, strings and arrays). Do not add a TOML
package. Put the reader in the project.

### 3. The preprocessor (stage 1)

As `transpiler.md` section 2 stage 1 describes: `{$I file}` and `{$INCLUDE file}` expanded
textually with the include search rules Delphi 3 uses (the including file's directory first, then
the project's search path, case-insensitive), `{$IFDEF}`, `{$IFNDEF}`, `{$ELSE}`, `{$ENDIF}`,
`{$IFOPT}` with `WIN32`, `VER100` and `CPU386` defined, `{$DEFINE}` and `{$UNDEF}` honored, every
other directive recorded with its position and kept out of the token stream. A map from every
output position back to the source file and line, so that every later error names `file:line` in
the original file. Source files are read as Windows code page 1252
(`Encoding.GetEncoding(1252)` with `CodePagesEncodingProvider` registered).

### 4. The lexer (stage 2)

Case-insensitive identifiers and keywords (Delphi 3 reserved words and directives, with directives
such as `read`, `write`, `index`, `name`, `message` treated as identifiers outside the positions
where they are directives), integer literals including `$` hex, real literals, `#nn` and `#$nn`
character codes, `'` strings with `''` escapes, and concatenations like `'a'#13#10'b'` as one
string token whose value is the bytes. Comments in `{ }`, `(* *)` and `//`. `{$` starts a
directive, not a comment. Tokens carry their source position through the map of stage 1.

### 5. The parser (stage 3)

A hand-written recursive descent parser for Delphi 3 Object Pascal (the Delphi 3 Object Pascal
Language Guide is the grammar), producing a syntax tree of C# records. It parses:

- Units: `interface`, `implementation`, `uses`, `initialization`, `finalization`, `begin ... end.`
  Programs (`.dpr`) and packages (`.dpk`: `requires`, `contains`) at the level needed to list
  units.
- Every declaration: `type`, `const`, `resourcestring`, `var`, `threadvar`, `label`, `procedure`,
  `function`, `constructor`, `destructor`, class methods, `forward`, `external`, calling
  conventions, directives (`virtual`, `override`, `abstract`, `dynamic`, `reintroduce` is not in
  Delphi 3, `overload` is not either), `absolute`, typed constants with record and array
  initializers.
- Types: simple, subrange, enumeration, set, array (static, open array parameters, `array of
  const`), record (packed, variant parts), string and `string[N]`, pointer, procedural (`of
  object`), class (visibility sections, fields, methods, properties with every specifier,
  `class of`), interface types to the extent the RTL interface sections use them, `file of`,
  `text`.
- Statements: every statement form including `with`, `case` with ranges and `else`, `try`
  `finally` and `except` with `on E: T do` and `else`, `raise ... at`, `goto` and labels, `asm ...
  end` bodies captured as raw text with their position (not parsed).
- Expressions: the full precedence table, set constructors with ranges, `@`, `^`, `is`, `as`,
  `in`, casts written as calls, `inherited` with and without a name, address-of on procedures,
  `nil`, and function calls without parentheses (the parser records them as names; deciding which
  names are calls is the resolver's job).

The constructs `transpiler.md` section 2 stage 3 lists as not in Delphi 3 are a parse error with a
clear message, not silently accepted.

The tree records the source position of every node. A test can build a tree by hand.

### 6. The command

`dotnet run --project tools/transpile/Transpiler -- parse --source D:\git\aow\src\delphi3 --rtl
C:\Tools\Delphi3\SOURCE [--unit <name>]` parses every unit of `units.toml` with treatment
`transpile` and, for each unit, the interface sections of every unit its `uses` clauses name,
found in the transpile set, in `--rtl` (`RTL\SYS`, `RTL\WIN`, `VCL`, `TOOLSAPI`) or in
`src/delphi3/imports`. It prints one line per file (`ok` or the first error with `file:line:col`)
and a summary: files parsed, lines, errors. Exit code 0 when there is no error. A unit name that
no search path resolves is an error.

## Tests

In `tools/transpile/Transpiler.Tests/`:

- Preprocessor: nested `{$IFDEF}`, `{$IFOPT}`, includes with case-insensitive names, the position
  map across an include.
- Lexer: every literal form above, the string concatenation case, `''` escapes, the three comment
  forms, `{$` versus `{`, keywords in any case.
- Parser: one test per construct group of section 5 above, written as small Delphi snippets with
  assertions on the tree shape. At least the cases section 10 of `transpiler.md` counts: `with`,
  `case`, nested routines, typed constants, `absolute`, variant records, `class of`, properties
  with `index` and `default`, method pointer types, `try` forms, `goto`.
