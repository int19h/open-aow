List every class in scope first in the status file with its bodies and the shape the rule gives
it.

- **Plain:** the body only assigns fields, allocates private children, or calls virtual methods
  whose overrides do the same.
- **Context-guarded:** the body publishes the object (owner insertion is already done by
  `EObject`, so this means a further list, cache, global or registry) or acquires something its
  `Destroy` releases, and later work on the chain can throw.
- **Not converted:** anything that fits neither cleanly (work before the base body that the base
  observes, a skipped base initializer, reentry on an existing object, a raw `NewInstance`
  consumer). Leave such a class as it is, list it in the report with the line and the reason, and
  continue with the rest. Do not stop the run for it.

The design note marks `NewCombatRoundCA` (Delphi `TNewCombatRoundCA`) (no body, created through `CombatAction`'s
initializer) as a class whose created type must stay exact. Check every inherit-only class in your
scope the same way: its creation route gives the descendant type, never the parent.

Keep ordinary virtual calls at their current positions and `base.X()` calls that stand for Delphi
`inherited` as non-virtual calls. Do not move work into field initializers. A parameterless
constructor stays only for a named raw consumer. Callers inside your worktree use `new` or the
guarded factory. Callers in the private repository are listed in the report with a ready patch.
A static factory with a `new` modifier that no longer hides anything loses the modifier. Do not
add warning pragmas.
