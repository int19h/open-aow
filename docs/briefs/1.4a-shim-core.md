# Brief 1.4a: the RTL shim core types and the System unit

The shim part of milestone 1.4 of `docs/milestones.md`, ahead of the emitter. Specification:
`docs/specs/rtl-shim.md` sections 1 (all), 2 (all), 6 and 8, and `docs/specs/transpiler.md`
sections 4 and 5 for how generated code uses each type. Read `docs/design.md` sections 2 and 3
first. All in `D:\git\open-aow\docs\`.

You work in `D:\git\open-aow`, the product repository. Its `AGENTS.md` holds the standing rules.
Read the Delphi 3 sources under `C:\Tools\Delphi3\SOURCE` (`RTL\SYS\SYSTEM.PAS` and the `.ASM`
files beside it are the reference for section 2) and the probe outputs under
`D:\git\open-aow-private\tests\probes\expected\` freely. Write only under `D:\git\open-aow\src\`
and the solution file at the repository root.

## What to build

- `OpenAow.slnx` (or `.sln`) at the root, `src/Rtl/Aow.Rtl.csproj` (class library) and
  `src/Rtl.Tests/Aow.Rtl.Tests.csproj` (xUnit). The root `Directory.Build.props` applies. The Rtl
  project allows unsafe code. Namespace `Aow.Rtl`, with the generated code's view of it as
  `using static` imports where the spec says so.
- Every type and member of `rtl-shim.md` section 1: `TObject` with `Meta` and `MetaRegistry`,
  `AnsiString`, `TSet<E>`, `Ptr<T>`, `PtrBox<T>`, `Bytes.Of`, `Box`/`Unbox`, `IntOrRef`,
  `TVarRec`, the exception hierarchy of 1.7 (with `EAbstractError`), `FixedArray`, exactly as
  specified, with the semantics the spec states.
- Every routine of section 2: `Random` and `RandSeed` (2.1), rounding and arithmetic (2.2), the
  System string routines (2.3), memory and the rest of 2.4.
- The behaviors of section 6 that touch these types.

Where the spec and the Delphi 3 source disagree, the source wins: write the source's behavior,
add a test that shows it, and list the disagreement in the report. Where the spec is silent on a
detail the source answers, follow the source and note it.

## Tests

Unit tests for every public member, in the form section 8 describes. The probe outputs are
fixtures:

- `random.txt`: every `RandSeed` and value line reproduced by the shim from the same calls. The
  probe source `D:\git\open-aow-private\tests\probes\random.pas` shows the calls. Read the
  expected file from that path at test time, and skip the test with a clear message when the path
  does not exist (the product repository does not contain the private one).
- `floats.txt` for `Round`, `Trunc`, `Int`, `Frac`, with the probe's scaling.
- `strings.txt` for `Copy`, `Delete`, `Insert`, `Pos`, comparisons and aliasing, where the
  members are in sections 1.2 and 2.3 (the SysUtils ones are a later brief, so skip their lines).
- `sets.txt` for `TSet<E>` masks, images and storage sizes.
- `integers.txt` for the arithmetic helpers of 2.2, including the Boolean byte rule of
  `transpiler.md` section 7 trap 9.

A test that compares against a probe file names the probe line it checks, so that a failure
points at the Delphi fact.

## Out of scope

SysUtils, Classes, the VCL parts (sections 3 to 5), the host interface (section 7), the
transpiler, anything in `D:\git\open-aow-private` or `D:\git\aow`.

## Done measure

1. `dotnet build` at the repository root with zero warnings, `dotnet test` passes, with no probe
   test skipped on this machine.
2. R1 of `rtl-shim.md` section 8: the core types of section 1 exist with tests, and a
   hand-written C# file in the style of the transpiler's output compiles against them. Write that
   file as `src/Rtl.Tests/GeneratedStyleSample.cs`: a small Delphi-like unit (a class with a
   `Meta`, a virtual constructor through a class reference, a record struct with a set field and a
   `string[N]` field, a `Ptr<T>` walk over an array, a `with` block as a scoped local, a typed
   constant), following `transpiler.md` sections 4 and 5 for each construct, with a test that
   runs it.
3. The `random`, `floats` and `sets` probe fixtures pass in full, and the `strings` and
   `integers` lines in scope pass.

Report the output of 1, the list of spec disagreements and silences you resolved from the source,
the probe lines you skipped as out of scope (counts by reason), and anything not done.
