# Brief 9.0: the hand-over, from generated output to source

The first step of the second stage (`docs/design.md` sections 3 and 9, `docs/milestones.md`
section 9). Milestone 2.4 passed long ago and the rules, the frames, the scenarios and the audio
all equal the original, so from here the C# tree is the source of truth: the transpiler stops
writing into the product, and every later change is a hand edit, checked by the oracle and the
frames. This brief makes the tree look like source instead of output, without changing what it
does.

You work in `D:\git\open-aow` on the branch the prompt names, and in `D:\git\open-aow-private`
under `tools` and `tests`. Read both `AGENTS.md` files, `docs/design.md` sections 3, 8 and 9, and
`docs/specs/transpiler.md` section 8 (the override mechanism being retired here).

## What to do

1. **A last regeneration** from the current transpiler and manifest, checked byte-identical to the
   tree in the repository, so that the hand-over starts from exactly what the transpiler produces.
2. **`src/Generated` becomes `src/Units`**, the project `Aow.Generated` becomes `Aow.Units`, and
   every project reference, solution entry, script and check path follows. The namespaces are
   already `Aow.Units.*`. The generated file headers that say "generated, never edit" become a
   one-line note naming the Delphi unit the file was translated from.
3. **The overrides fold in.** Each override file under `src/Overrides/<Unit>/` moves beside its
   unit in `src/Units/` (a partial class file beside the unit's file is fine at this stage), the
   skip entries of `src/Overrides/overrides.toml` and the matching gaps in the units disappear
   together, and `overrides.toml` and the transpiler's skip mechanism are no longer used by the
   product. `src/Overrides` is gone at the end.
4. **The layouts** compile into `Aow.Units` through the project file itself, not through
   `src/Layout/Layout.targets` and the root `Directory.Build.targets`, which go away.
5. **Rules and documents.** Remove "never edit `src/Generated`" from both `AGENTS.md` files and
   the track rules, and state the new rule: the units are source, edited by hand, and every edit
   keeps `python tools/check.py` passing. Update `docs/design.md` section 8 (the layout), section 3
   (the lifecycle: the hand-over happened on this date), `docs/process.md` and `transpiler.md`
   section 8's status (retired for the product, kept for reference diffs of upstream changes).
6. **The tooling.** `tools/check.py`, the oracle, the frames and the probes run against
   `src/Units`. The transpiler stays in the private repository with an `emit --out <dir>` that
   writes somewhere other than the product, for comparing an upstream change with the hand-edited
   tree.
