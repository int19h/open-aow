## What to build

1. **The round-trip tool**, `tools/oracle/RoundTrip/` in the private repository: a .NET console
   project referencing `D:\git\open-aow\src\Generated\Aow.Generated.csproj`. It takes a save
   (`.asg`) or map file, loads it through the generated engine's own load path (the routine the
   game calls, not a hand-written reader), writes it back through the generated save path, and
   compares the inflated payloads of input and output (`persistence.md` section 1.2: the
   container is decompressed on both sides, so the compression backend does not matter). It
   prints `equal` or the first differing inflated byte offset with the property path
   `asg_dump.py` gives for that offset (run it from the tool, read only, for the diagnosis), and
   exits 0 or 1. A `--all <dir>` mode runs every save and map under a directory.
2. **Startup for a headless load.** Whatever unit initialization and engine setup the load path
   needs (the class registry, the property tables, the data files the engine reads before a load)
   without a window, sound or display: a minimal host in the tool that sets the shim's file
   system and clock defaults and calls the generated `InitializeAll`. Anything the load path
   reaches that needs the UI or a platform service gets a stub in the tool or a shim default,
   listed in the report.
3. **Fixes.** Every TODO the load and save path reaches becomes an override under
   `D:\git\open-aow\src\Overrides` (from the Delphi source, the recovery's notes and the catalogue)
   or a transpiler fix, and every byte difference is a transpiler, shim or override bug until shown
   otherwise. Fix it at its cause, never in the generated output and never in the comparison.
   Keep a list: TODO or difference, cause, fix.

the save (a time stamp, a random seed read at save time), stop on it and report it with the
