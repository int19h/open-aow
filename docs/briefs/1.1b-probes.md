## The probes

`with`, `case`, `loops`, `exceptions`, `classes`, `properties`, `evalorder`, `lists`, `streams`,
`typed-constants`, `init-order`, `files`. The rows of the table in `testing.md` section 2 are the
minimum content of each. Notes:

- `evalorder`: built from `from-recovery/order.pas` and `order2.pas` (read their README): a
  tracing function prints its tag, so the output is the order of evaluation. Cover every case of
  the table row and of those two files, and the traps of `transpiler.md` section 5.4.
- `exceptions`: catching an access violation (`EAccessViolation`) and a division by zero
  (`EDivByZero`) prints the exception class name and nothing that varies (no address in the
  message: print the class name only).
- `classes`: every case of traps 18 to 21 of `transpiler.md` section 7, plus `ClassName`,
  `ClassParent`, `InheritsFrom`, `InstanceSize` of a few classes, a virtual constructor called
  through a class reference that creates the dynamic class, and `Free` on `nil`.
- `init-order`: a program and three units under `tests/probes/init-order/` whose
  `initialization` and `finalization` sections print, built in two `uses` orders as two programs
  (`init-order-a`, `init-order-b`). Extend the runner so a probe can be a directory with more than
  one program, and describe the extension in the README.
- `lists`: `DelphiList.Sort` (Delphi `TList`) with a comparison that has many equal keys, on several sizes (the order of
  equal keys is the point: print the identities), `Capacity` growth after each `Add`, `Insert`,
  `Delete`, `IndexOf`, `Exchange`, `Pack`, and `StringList` (Delphi `TStringList`) with `Sorted` and each `Duplicates`
  value, `Find`, `IndexOf`, `CaseSensitive` is not in Delphi 3 (check, do not use if absent).
- `streams`: `TMemoryStream` and `TFileStream` (in the build directory), `Position` and `Size`
  after every operation, writes past the end, `Seek` with each origin and out of range, `CopyFrom`
  with count 0, `ReadBuffer` past the end (exception class name).
- `files`: a prepared directory created by the probe itself under the build directory (files and
  subdirectories with names chosen to show the order `FindFirst` returns, mixed case, and
  attributes), then `FindFirst` and `FindNext` with each attribute mask, and `ExtractFileName`,
  `ExtractFilePath`, `ExtractFileExt`, `ChangeFileExt`, `ExpandFileName` on relative paths (print
  results relative to the build directory, never absolute paths).
