## Scope

Every class with a split initializer or a guarded static factory in `src/Units/HSEngine.cs` and
its partial files, `src/Units/NetworkE.cs`, `src/Units/Sound.cs`, and the sound classes in
`src/Platform/SdlSoundSystem.cs`. `src/Units/IsoHex*.cs` is out of scope (its raw
`NewInstance` plus `Attach` path stays).

List every class in scope first in the status file with its bodies and the shape the rule gives
it.

- **Plain:** the body only assigns fields, allocates private children, or calls virtual methods
  whose overrides do the same.
- **Context-guarded:** the body publishes the object (owner insertion is already done by
  `EngineObject`, so this means a further list, cache, global or registry) or acquires something its
  `Destroy` releases, and later work on the chain can throw.
- **Not converted:** anything that fits neither cleanly (work before the base body that the base
  observes, a skipped base initializer, reentry on an existing object, a raw `NewInstance`
  consumer). Leave such a class as it is, list it in the report with the line and the reason, and
  continue with the rest. Do not stop the run for it.

Two families need the context, as the design note's failure table shows. The dynamic map level
(`HSEngine.cs`, the creation near the `Clear` catch) attaches itself to the container through
`SetOwner` before later work. The sound sample data inserts itself into `SampleDataList` and then
loads its file, and the sample adds itself to `SampleList` and increments the data reference count.
Pin the list memberships and reference counts after a failing load (a missing or corrupt WAV,
without playing audio) on the base commit, then keep them. `SdlSampleData` lives in `Aow.Platform`,
which does not see RTL internals: make `ConstructionContext` and its members public, as the
architecture decision in `ctor-design.md` says. The design note also keeps the combat-map global
ordering (`CombatMap` (Delphi `TAoWCombatMap`)) as an exception, and `MapField` (Delphi `TMapField`)'s metadata (`InstanceSize`, the dynamic
field class) stays. Keep the `HSEngine.CreateHexSpriteSet` (Delphi `THSEngine`) and `HSMap.CreateMouse` (Delphi `THSMap`) virtual calls where
they are.

Keep ordinary virtual calls at their current positions and `base.X()` calls that stand for Delphi
`inherited` as non-virtual calls. Do not move work into field initializers. A parameterless
constructor stays only for a named raw consumer. Callers inside your worktree use `new` or the
guarded factory. Callers in the private repository are listed in the report with a ready patch.
A static factory with a `new` modifier that no longer hides anything loses the modifier. Do not
add warning pragmas.
